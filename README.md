# Landing Page - Tutoriais SoftExpert

Landing page profissional para organizar e apresentar tutoriais sobre licenciamento, créditos do Copilot e processos de down-upgrade/upgrade da plataforma SoftExpert.

## 🎨 Design & Características

- **Identidade Visual SoftExpert**: Cores corporativas (azul #003D7A, branco, amarelo #FFA500)
- **Design Minimalista Corporativo**: Espaço em branco generoso e hierarquia tipográfica clara
- **Tipografia Elegante**: Poppins para títulos, Inter para corpo
- **Animações Suaves**: Fade-in ao carregar, stagger nos cards, hover effects
- **Totalmente Responsivo**: Funciona perfeitamente em mobile, tablet e desktop
- **HTML Puro**: Sem dependências externas, pronto para publicar

## 📁 Estrutura

```
landing-page-html/
├── index.html          # Arquivo único com HTML, CSS e estrutura
└── README.md           # Este arquivo
```

## 🚀 Como Usar

### Localmente
1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em um navegador web
3. Pronto! A página carregará com todos os efeitos

### No GitHub Pages
1. Crie um novo repositório no GitHub
2. Faça upload dos arquivos
3. Ative o GitHub Pages nas configurações do repositório
4. Sua página estará disponível em `https://seu-usuario.github.io/nome-do-repo/`
